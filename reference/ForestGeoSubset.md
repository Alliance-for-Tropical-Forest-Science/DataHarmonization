# ForestGeoSubset

Stem tables from Luquillo produced with [**rtbl**
0.0.0.9000](https://github.com/forestgeo/rtbl/releases/tag/0.0.0.9000),
with Species table merge into it and some alteration of dbh for
troubleshooting purpous. NOT SUITABLE FOR DATA ANALYSIS.

## Usage

``` r
ForestGeoSubset
```
